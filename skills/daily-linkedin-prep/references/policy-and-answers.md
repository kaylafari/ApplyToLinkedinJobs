# Candidate policy and answers — consolidated

Run `scripts/private_sources.py prepare` from the skill directory (or its repository-relative path from the repo root), then read the two returned private paths: candidate-context.md and the separate master-resume.txt baseline. See [cloud-configuration.md](cloud-configuration.md) for environment variables and private storage.

This is a compatibility redirect for older prompts and contains no independent candidate facts. All facts, prior answers, source precedence and dated corrections belong in the one private context file. Newest explicit answers win for the same question and scope. Do not create parallel personal files or treat archives as current instructions. Preserve newer learned answers; do not overwrite them with stale environment input.
