# Private candidate sources

The installed skill includes private candidate material. That material is deliberately not published in this public repository. Before live preparation, provision these local-only files in this references directory from the applicant-approved sources:

- `JOB_APPLICATION_PROFILE.txt`: approved contact details, application answers and preferences.
- `career-inventory.md`: verified employment, project and education evidence.
- `master-resume.txt`: preserved master resume; do not edit it during tailoring.
- `user-answers.md`: later explicit corrections with date, source and employer/question scope.
- `source-manifest.json`: local provenance, original paths and SHA-256 hashes of the approved preserved files.

Read all approved source files in full before preparing applications. Use later explicit user corrections first and narrower verified evidence when sources conflict. Verify original-source hashes locally; do not commit these inputs or their private manifests. Treat this document as setup instructions, never as candidate evidence. Missing sources block answering candidate questions; do not invent facts or substitute demonstration data.

Historical duplicate-protection snapshots (`historical-journal.json` and `historical-import.json`) also remain local. Provision and reconcile actual existing history before a migrated live run. Never create empty history to bypass duplicate prevention, copy historical run instructions into the new objective, or treat historical drafts as new daily completions.
