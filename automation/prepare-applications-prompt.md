# Recurring preparation workflow template

Use automation/cloud-task-prompt.md and the repository's daily-linkedin-prep skill
in hybrid mode. This is a saved prompt template, not a running schedule or service.

Retain the existing daily 02:00 America/Los_Angeles schedule, 15-application objective
and saved gpt-6-astra / High settings where already configured. A prompt does not
configure those settings. Do not create/unpause/update a schedule unless explicitly
requested. A later user stop/scope instruction always controls the run.

Cloud prepares versioned private packets/documents independently of the laptop.
Use the actual computer browser when its supported connection is available;
otherwise preserve browser work for the local coordinating agent following
automation/local-browser-task-prompt.md. Offline packets do not count as filled
applications. Preserve full history and current approved personal sources.

Use manual download/transfer with checksums per references/manual-transfer.md.
Keep handoff waiting until local retrieval is verified; no shared drive is required.
Use the finite batches, ownership, one-application cap, Notion
outbox and manual-submission boundary in references/hybrid-workflow.md. When the
computer is offline, continue only useful independent preparation. Do not loop
polling for browser access or assume automatic restart/indefinite cloud execution.

Report meaningful new completion, blockers or required human action. Keep unchanged
non-actionable follow-ups quiet. Checkpoint on limits/interruption, preserve newer
context and state privately, never put the computer to sleep, and never submit.
